# Targeted ROW records retrieval package

These are **draft search scopes**, not communications already sent. They are written to retrieve records tied to this exact route instead of requesting an entire county archive. Attach a station map and cite the feature IDs/coordinates. Ask the records custodian to identify the appropriate office if a record is held by another division.

## Common exhibit and request controls

For every authority, attach a one-page map showing the proposed route in a bright color, feature IDs, endpoint coordinates, 100-ft context, road names, county/city/township lines, and a scale/north arrow. Also include `master_feature_matrix.csv` filtered to that authority. Do not describe the route as occupying any agency's ROW until the agency confirms jurisdiction.

Request electronic originals or best available searchable/scanned copies, including sheet borders, legends, revision dates, title sheets, acquisition lines, temporary easements and recorded-document references. For each returned document, log custodian, query date, source, plan/record number, sheet/page, road, station/coordinates, scale/CRS, revision status, legal instrument/recording reference, and applicable feature IDs. If nothing is found, log the search terms, index/map layers queried, office contacted and no-record response.
