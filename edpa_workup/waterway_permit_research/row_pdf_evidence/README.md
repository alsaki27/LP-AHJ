# ROW PDF evidence library

This folder holds original publicly available road, ROW, acquisition, plat, deed, utility-permit and roadway-plan PDFs for the supplied S0, S1 and Chicago spurs. `S0/`, `S1/` and `Chicago/` keep source scans separate by route. `master_evidence_catalog.csv` records source, page count, SHA-256 and candidate route feature/station. `master_pdf_file_inventory.csv` validates each included file. `missing_controlling_pdf_register.csv` identifies indexed scans still needed.

## Evidence grades

- **A - station verified:** a plan or recorded legal description has been tied to the source route and proposed bore pits, trench, vault, access and staging area.
- **B - road/feature candidate:** the document concerns the named road or project near the feature, but its plan station or property limits are not yet tied to the proposed work area.
- **C - locator or precedent:** an official index, general map, or older permit identifies where to search; it does not grant this project ROW rights.
- **M - missing scan:** an identified controlling document is not available as a downloaded public PDF; log the portal, reference number and needed request.

An assessor parcel, mapped ROW polygon, or plan-index hit by itself cannot choose a lawful road side or trench location. The final engineering decision needs the actual rights and plan limits, current surface/utility plans, vertical clearance, construction work envelope, and field verification.
